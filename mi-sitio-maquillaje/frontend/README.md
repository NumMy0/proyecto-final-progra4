# Frontend - Mi Sitio Maquillaje

Instalación y ejecución rápida:

```bash
cd mi-sitio-maquillaje/frontend
npm install
npm run dev
```

El frontend hace un `fetch` a `http://localhost:8080/api/productos` para listar productos.
Asegúrate de iniciar el backend Java (`RestServer`) antes de cargar el frontend.
